# Testimonials Grid Section

A responsive testimonials grid section component built as part of a Frontend Mentor challenge.

## Overview

### The Challenge
Users should be able to view the optimal layout for the site depending on their device's screen size (Mobile & Desktop).

---

## My Process

### Built With
- Semantic HTML5 markup
- Tailwind CSS (v4)
- CSS Grid & Flexbox
- Mobile-first workflow
- Google Fonts (Barlow Semi Condensed)

### What I Learned
- Structuring complex card layouts using CSS Grid (`grid-cols`, `col-span`, and explicit grid positioning).
- Utilizing Tailwind CSS v4 for modern, utility-first styling.
- Adding decorative background patterns to grid cards.
- Managing responsive layouts cleanly across mobile, tablet, and desktop viewports.
